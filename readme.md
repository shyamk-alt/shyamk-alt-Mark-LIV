## 🌟 Overview
MARK LIV (54) is a personal AI that lives on your machine.
I, Shyam K, built MARK LIV to solve one problem: Why should my personal AI live in someone else's cloud?
MARK LIV runs locally, understands voice in real-time, sees your screen, controls your computer, and helps you build faster.
No monthly fees. No data harvesting. Your AI, your rules.

## ✨ Key Features
### 🎤 Real-Time Voice Native
- Full duplex audio streaming
- Interruption support — talk anytime
- Natural human-like conversation
- Zero typing needed

### 👁️ Vision & Screen Understanding
- Sees your screen in real-time
- Understands UI, code, documents, images
- Can debug code by looking at your VS Code
- Can read PDFs, images, websites

### 🖥️ Full Computer Control
- Opens apps, files, browsers
- Writes code, creates files, edits docs

- Controls mouse and keyboard safely

- Works on Windows 11/10
- Works on macOS Intel & Silicon

- One codebase, zero compromises

### ⚡ Powered by Gemini Live API
- Native audio-to-audio model
- Ultra-low latency < 500ms
- Multimodal understanding
- No STT/TTS lag

### 🔓 100% Private & Yours
- Runs on your machine
- Your API key, your control
- No data sent to third parties
- Open source and auditable

## 🏗️ Architecture
USER -> Audio Engine -> Vision Engine -> Memory System -> Gemini Live API -> Tool Engine -> Action Planner -> PC Control -> YOUR COMPUTER

## 🛠️ Tech Stack
- Brain: Gemini Live API - Real-time AI
- Language: Python 3.11+ - Core logic
- Audio: PyAudio, WebRTC - Voice streaming
- Vision: MSS, PIL, OpenCV - Screen capture
- Control: PyAutoGUI - PC automation
- Memory: Local JSON + Vector - Personal memory

## 🚀 Quick Start - 30 Seconds
### Prerequisites
- Python 3.11 or higher
- Gemini API Key from Google AI Studio
- Microphone and speakers

### Installation
git clone https://github.com/shyamk-alt/shyamk-alt-Mark-LIV.git
cd shyamk-alt-Mark-LIV
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
echo GEMINI_API_KEY=your_key >.env
python main.py
